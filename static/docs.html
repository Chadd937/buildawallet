Developer docs

Read-only public wallet data on Base and Solana mainnet. Six metered subscription endpoints, a batch endpoint, a stateless MCP tool server, and two existing x402 pay-per-request endpoints. No signing or custody.

1. Choose a plan and sign in

Builder ($12), Pro ($39), Scale ($99) each include 30 days of the HUMAN premium blueprint and API usage. Connect the wallet that will pay, sign the one-time login challenge, then transfer the selected plan's exact native USDC amount on Base or Solana. Confirm its transaction ID. The server checks payer, collector, token, amount, confirmation and replay. An API key can then be created on the same payment page. Renewal requires another payment.

2. Call the API

curl -H 'Authorization: Bearer baw_live_YOUR_KEY' \
  'https://buildawallet.xyz/machine/v1/base/wallet/0xBcCA6AED433d9020C50D44560F9679F1B5eB511d'

curl -H 'Authorization: Bearer baw_live_YOUR_KEY' \
  'https://buildawallet.xyz/machine/v1/usage'

The six read endpoints cover native wallet balance, native USDC balance, and transaction status for each chain. A successful read costs one unit; failed validation or RPC lookups do not. Pro batches support up to 10, Scale up to 50, with each item counting as one unit. Check interactive Swagger or OpenAPI 3.1 JSON for every request, response, error, and plan.

3. Use MCP

Point an MCP HTTP client to https://buildawallet.xyz/mcp with Authorization: Bearer baw_live_YOUR_KEY. The six read-only tools use the same quota as REST. Public tool discovery is available without spending API units. Agents can discover the API through agent.json, agent-offer.json, and llms.txt. Never put the API key in a crawler-facing file.

4. Pay only for a single snapshot

GET /machine/wallet?address=0x... and GET /machine/solana-wallet?address=... charge $0.01 native USDC per request via x402 on either Base or Solana. Request without payment to receive a standard HTTP 402 challenge containing network, token, exact amount and recipient. Retry with an x402-capable client. These endpoints are distinct from the API key subscription.

Scope and status

This production API observes public chain state. The local agent wallet/signing prototype is not mounted on this service. No endpoint creates, holds, signs for, or transfers wallet funds. RPC and Cloudflare bindings must be configured for each capability. Check /machine/info for current configuration and /machine/human/subscription for payment availability before sending USDC.
