Developer docs

Base and Solana mainnet machine services: metered public-data reads, non-custodial transaction preparation, already-signed transaction broadcast, MCP tools, and x402 pay-per-request reads. BuildAWallet never accepts a seed phrase or private key.

1. Subscribe to the machine API

Builder ($12), Pro ($39), Scale ($99) provide 30 days of metered machine API usage. HUMAN wallet design and Android release are free. Connect the wallet that will pay, sign the one-time login challenge, then transfer the selected plan's exact native USDC amount on Base or Solana. Confirm its transaction ID and create the API key. Renewal requires another payment.

2. Read Base and Solana state

curl -H "Authorization: Bearer $BAW_API_KEY" \
  'https://buildawallet.xyz/machine/v1/base/wallet/0xBcCA6AED433d9020C50D44560F9679F1B5eB511d'

curl -H "Authorization: Bearer $BAW_API_KEY" \
  'https://buildawallet.xyz/machine/v1/usage'

Single reads cover native balance, native USDC balance, and transaction status for both chains. A successful single read costs one unit. A composite native + USDC snapshot costs two. Failed validation or upstream RPC failures are not metered. Pro batches support up to 10 items and Scale up to 50.

3. Prepare a transaction without giving up custody

Use POST /machine/v1/base/transaction/prepare or POST /machine/v1/solana/transaction/prepare. Each successful preparation costs one API unit.

Base returns a wallet-signable EIP-1559 transaction with current nonce, gas estimate, and fee fields. It supports native ETH on Base and native Base USDC.

Solana returns a serialized legacy transaction with a zeroed signature slot. It supports native SOL and native Solana USDC. For USDC, provide the source and destination token-account addresses.

Sign in your own wallet. Do not send a private key, seed phrase, or recovery secret to BuildAWallet.

4. Broadcast an already-signed transaction

POST /machine/v1/base/transaction/broadcast
{ "signedTransaction": "0x..." }

POST /machine/v1/solana/transaction/broadcast
{ "signedTransactionBase64": "..." }

Base relays raw signed EVM transaction hex through eth_sendRawTransaction. Solana relays an already-signed base64 transaction through sendTransaction with preflight enabled. A successful broadcast costs one API unit. BuildAWallet does not sign for you.

5. Use MCP

Point an MCP HTTP client to https://buildawallet.xyz/mcp with Authorization: Bearer your issued API key. Read tools use the same quota as REST. Transaction tools are base_prepare_transaction, base_broadcast_transaction, solana_prepare_transaction, and solana_broadcast_transaction. The api_usage and service_quote tools are free. The x402 pay-per-call wallet tools remain available without an API key.

6. Pay only for a native wallet snapshot

GET /machine/wallet?address=0x... and GET /machine/solana-wallet?address=... charge $0.01 native USDC per request via x402 on either Base or Solana. Use the free quote endpoint first, then rely on the live HTTP 402 challenge as the authoritative payment request.

Scope and status

The production service reads public chain state, prepares unsigned wallet-signable transactions, and relays signed transaction bytes. It is non-custodial: there is no endpoint for a seed phrase, private key, or server-side signing. Check OpenAPI 3.1, Swagger, machine info, and current machine-plan availability before use.
